Patch Notes

What changed in each update, newest first.

Version 0.3.2

Latest

Version 0.3.2 is live. Please restart Steam if you don't see the update.

Saved runsMultiplayerRadio & soundLoading & graphicsRPGLeaderboards & replaysCustom mapsOther

Saved runs

  • Runs are now kept between sessions: leave mid-run and pick it up later from the pause menu's new SAVED RUNS page
  • A resumed run goes back to your last save with the clock, saves, loads and rockets exactly as they were, and still counts for the leaderboard with one replay across every session
  • Only a restart throws a run away: leaving the map, KEEP THIS RUN or switching to another run all keep it
  • Up to 20 runs per map, named RUN 1, RUN 2 and so on, and renamable; they save themselves as you play and are stored on Steam Cloud
  • The restart prompt and NEW RUN now say whether your run is kept before you throw it away
  • Practice no longer leaves its weapon switches and loads in your run's replay

Multiplayer

  • When the host leaves, the game carries on: the player with the best connection takes over and everyone moves to their game automatically, with your run picked up from its last save
  • New lobby finishes card: see when someone in the lobby finishes a route, with their time and whether it was a record, a lobby best or a PB (a HUD element, ALL or BESTS ONLY)
  • Everyone now spawns exactly on the start; fixed spawning inside walls or far away on some maps
  • Fixed a host crash when a player joined twice in quick succession
  • Chat works with the chat HUD element turned off, and stays up while watching replays and in free cam
  • Standing still with the pause menu open in a lobby now holds your run clock, like spectating
  • The RPG reload bar now shows the player you're spectating instead of getting stuck
  • VOTE KICK moved to the far end of a player's row, away from SPECTATE

Radio & sound

  • New radio: music on the menu and in maps, with a card showing the song when it starts
  • Every song plays once before any repeats, in a new order each time, and all songs play at the same loudness
  • Pause and skip songs from the pause menu, or bind keys for them in CONTROLS
  • New SOUND settings tab: master volume, game sounds, radio on/off and volume, and the song card
  • Master volume now starts at 25% and no longer gets louder when a map loads

Loading & graphics

  • New loading screen with the map's picture, author, routes, your best and how many saved runs you have there, plus a tip
  • It stays up until the map's shaders and textures are ready, so the map no longer stutters when you start playing
  • On first launch the game now picks graphics settings for your PC; GRAPHICS has an AUTO-DETECT button to do it again

RPG

  • With RPG switch on, loading gives you the launcher back if you had it out for that attempt, so you don't have to draw it before every retry

Leaderboards & replays

  • LOW-RPG: a faster run with more rockets no longer replaces your lowest-rocket run
  • Maps with many routes: the route chips wrap onto their own row instead of running off the leaderboard, and map cards show the route count as a badge
  • Loads in replays now cut exactly instead of sliding the camera across
  • Your own weapon comes back correctly after watching a replay

Custom maps

  • Map makers can play their own videos on a screen in the map
  • Maps can turn the radio off (for maps with their own music or voicelines), or pause it from Blueprints
  • Maps that use the engine's built-in fonts now load; the game used to refuse them
  • Workshop items with more than one map now give each map its own leaderboards
  • The map kit now runs the same check the game does, and names every file the game would refuse

Other

  • Re-reading a tutorial step is now a rebindable action (default Y), and works in multiplayer
  • Debug text no longer shows on screen; important alerts get their own card
  • Typing in a pause-menu text box no longer closes the menu when you press M

Version 0.3.1

Player modelsRPGCustom maps

Player models

  • Other players are now an animated robot instead of a placeholder cylinder
  • Running, strafing, backpedalling, crouching, sprinting and jumping all animate, and the feet keep pace with how fast the player is moving
  • Running diagonally turns the legs while the upper body keeps facing where the player aims
  • The RPG sits on the shoulder with both hands on it, and the body leans to follow where the player looks up or down
  • Other players' rockets now come out of their launcher, and the loaded rocket disappears until they've reloaded

RPG

  • Rocket timing now matches the original: the push used to land 1–2 frames early, which is why the RPG could feel off

Custom maps

  • Maps using Ultra Dynamic Sky and Ultra Dynamic Weather now work
  • A map can't be published to the Workshop under a plugin name another creator's map already uses
  • The map kit's check now lists every problem in a map at once instead of one per Blueprint

Version 0.3.0

MovementRPGRunsLeaderboards & replaysSpectatingHUD & menusMultiplayerCustom mapsOther

Movement

  • Movement and collision went through a full review against the original game; lots of small fixes so it plays closer to it
  • Sprint has no time limit, lasts through the air, and ends on fire, jump, crouch, aiming or a second sprint press
  • Holding sprint through a jump brings sprint back mid-air (space and mouse-wheel jumps differ here, like the original)
  • Crouch can be held or toggled; if you can't stand up you stay crouched; the jump key stands you up from a crouch
  • Aiming slows walking like the original
  • Mouse-wheel jumps and other very short taps always register now
  • Landing and bounce detection is closer to the original, including how much speed a long fall costs
  • Sloped surfaces no longer hold you further away than they should
  • Invisible walls and ramps made with blocking volumes now collide exactly like normal level geometry
  • New ice surfaces in maps: no friction, and slopes slide you downhill

RPG

  • Pressing fire while sprinting now just ends the sprint; keep holding fire and it shoots once the launcher is up
  • New RPG switch option: the launcher is put away the moment it fires, for a clear view after a bounce
  • New RPG zoom option (off by default) with adjustable strength
  • A weapon put away mid-reload keeps reloading (this also closes the put-away reload skip)
  • RPG settings are now together under one RPG heading in Controls

Runs

  • Practice is fully separate from your run: rockets fired and moves made in practice no longer count toward it
  • Walking back into the start box without a save now resets the run, with a notice
  • Watching a replay mid-run pauses your run clock and no longer messes up your own run's recording
  • Watching a replay no longer gives you a free reload
  • Stepping back to an older save (hold LOAD + FIRE) now makes that save your current one
  • Fixed stepping back onto a start-box save resetting your load count

Leaderboards & replays

  • New leaderboard look: your run, your best with the PB difference, and your rank at the top, plus WATCH buttons
  • Routes are now chips you can click instead of arrows
  • LOW-RPG runs with the same rocket count in the same second are now decided by the milliseconds
  • Maps can have up to 32 routes with online leaderboards
  • Replays now pause on the last frame so you can scrub back or watch again
  • New replay viewer: timeline with saves, loads and rockets marked

Spectating

  • Pick who to watch from the scoreboard: hold Tab, right-click, then click a player (click yourself to go back)
  • See the watched player's keys light up, plus their PMOVE rate and speed
  • Free camera hides the HUD; the mouse wheel sets the fly speed
  • New card showing who is watching you, and who else is watching the same player
  • Your own launcher no longer shows while spectating
  • If the player you're following leaves, the camera moves to the next player instead of snapping back to you

HUD & menus

  • New HUD look to match the menus: notices with icons, vote card with countdown and YES/NO keys, new chat, restart prompt, name tags and FPS wheel
  • New default HUD layout (only applies if you never moved your HUD)
  • HUD editor shows every element's outline, name and size
  • Difficulty filter (ALL, 1-10) on SELECT MAP and when hosting
  • Type your own PMOVE rate (snaps to the closest rate the game can run)
  • Workshop lists maps by their in-game name

Multiplayer

  • A player losing connection no longer closes the host's lobby
  • Accepting an invite while already in a game now works
  • Chat spam limit to protect slower connections

Custom maps

  • Custom maps are checked more thoroughly before they load: a map can't touch your files, settings, the internet or the leaderboards
  • Map makers get new Blueprint nodes for launch pads, teleporters and low-gravity zones, plus more freedom for interactive maps
  • Replays downloaded from the leaderboards are checked before they load

Other

  • Developer console commands are no longer available to players
  • Fixed a hand-edited config breaking HUD scale or position
  • Unknown keys in the config no longer wipe a bind
  • Removed a leftover "Hello World" message on map start
